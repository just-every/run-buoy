## Existing guarantees

1. **HTTP-001 — Authenticated product HTTP** (`done`). Signed out, cross-origin, as a member and as an agent token, call every product route; unauthenticated reads return 401, cross-origin cookie writes return 403, and members cannot change accounts or approve. Send a scoped bearer preparation command without Origin and with a foreign Origin; both succeed and the proposal and audit event identify the agent. Attempt approval and account edits with the bearer token; both return 403, and an unsupported command is refused. Repeat with a session cookie alongside a valid token, then an invalid, expired or revoked token; the valid token keeps only its bearer scope and an invalid token cannot authorize a cross-origin session write.
