# Synthetic ChurnZero account mapping example

`accounts.csv` is a synthetic twenty-account CSV for the explicit column mapper. The headers are an example mapping contract, not a verified ChurnZero export schema. No customer export or versioned vendor schema was supplied. Select and review the actual headers from your export; the mapper never guesses them or supplies missing contract terms.

The fixture has explicit account identities, names, renewal dates, notice periods, contract references and invoice snapshots. `ChurnScore` and `ChurnScore Factors` can be explicitly mapped to a read-only native account observation using `churnScore` and `churnScoreFactors`. The example contains scores 4 through 80, a usage factor 1 through 20 and an engagement factor 19 through 0. No weights, bands or scoring rules are inferred. `Journey` and `Contact` remain unmapped source columns. Their values remain in the retained original CSV; review names each unsupported column for each source account. These observations create no native health measures, customer people or journeys. In particular, retained journey labels are not paused Buoy journeys and establish no steps or execution authority.

MIGRATE-002 stays partial. Native contacts, health configuration and measure mapping beyond retained observations, tasks, plays, success plans, paused journeys with definition mapping, events, NPS, API intake and full source-schema verification remain required. These bytes are used only for deliberate review or tests and are never imported automatically.
